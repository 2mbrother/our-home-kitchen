# 우리집 요리

사이트: https://2mbrother.github.io/our-home-kitchen/

## 메뉴 추가와 공유

누구나 로그인 없이 메뉴를 볼 수 있습니다. 새 메뉴 추가, 수정·삭제, 엑셀 가져오기는 편집 비밀번호가 필요합니다. 비밀번호는 서버에서 확인하며, 새로고침하거나 ‘편집 잠그기’를 누르면 다시 입력해야 합니다.

저장한 메뉴와 사진, 유튜브 링크는 공용 저장소에 반영됩니다. 다른 사람은 새로고침하면 볼 수 있고, 열린 목록도 약 15초마다 갱신됩니다. GitHub에 메뉴 파일을 따로 올릴 필요가 없습니다. 동시에 같은 메뉴를 수정했다면 새로 불러온 뒤 다시 수정하세요.

이전 버전에서 추가한 음식은 추가했던 기기와 브라우저로 접속해 새로고침한 뒤 **‘이 기기의 변경사항 공유’**를 한 번 누르고 편집 비밀번호를 입력하세요. 이전 브라우저의 편집본은 삭제하지 않습니다. 메뉴 관리에서 이전 편집본 백업도 내려받을 수 있습니다.

## 엑셀과 유튜브

메뉴 관리에서 엑셀 / CSV / JSON 백업을 가져올 수 있습니다. 첫 번째 시트의 열은 `idx`, `분류`, `요리`, `메인`, `민형_등수`, `유민_등수`, `요리시간`입니다. 분류는 메인 또는 반찬, ‘메인’ 열은 담당 요리사입니다. 같은 번호는 수정하고 새 번호는 추가합니다. 기존 사진과 메모는 유지합니다.

마지막 열에 `유튜브링크`를 추가하거나, 사이트의 메뉴 추가·수정 화면에서 직접 넣으세요. `유튜브 링크`, `YouTube URL`, 일반 영상·공유 링크·Shorts, Excel 하이퍼링크와 HYPERLINK 수식을 지원합니다. 링크 열이 없는 옛 엑셀은 기존 링크를 유지하며, 링크 열의 빈 셀은 기존 링크를 지웁니다.

## 메뉴판 PDF와 백업

음식 사진의 + 버튼으로 선택한 뒤 **PDF 만들기**를 누르면 선택한 음식의 PDF 파일을 바로 내려받습니다. 메뉴판 보기 → PDF 다운로드도 사용할 수 있습니다. ‘초기 메뉴판 PDF’는 처음 제공된 32개 음식의 고정본입니다.

메뉴 관리에서 공용 메뉴를 JSON 백업으로 내려받을 수 있습니다. 사진과 유튜브 링크도 포함됩니다.

## 운영과 개발

화면은 GitHub Pages, 공용 데이터와 편집 인증은 Supabase의 별도 kitchen_* 테이블과 kitchen-api Edge Function을 사용합니다. 데이터베이스는 일반 방문자의 직접 쓰기를 허용하지 않습니다. 서버 비밀키와 비밀번호는 게시 파일에 넣지 않습니다. 백엔드 소스와 스키마는 backend/에 있습니다.

Node.js 22 이상에서 npm install, npm run dev를 사용합니다. npm run build 결과는 docs/입니다. 실제 게시용 index.html은 스크립트와 글꼴을 하나로 묶은 파일입니다. public/recipes.json은 이전 브라우저 편집본을 복구하기 위한 초기 기준 자료이므로 최신 공용 메뉴로 덮어쓰지 마세요.

GitHub Pages 설정은 main 브랜치, /(root)입니다. 화면 코드를 변경할 때만 게시 파일을 GitHub에 업로드합니다.
